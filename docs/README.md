# Документация Render Node

- [Архитектура](architecture.md) — устройство проекта, границы модулей,
  REST/WS, выполнение Blender и модель безопасности.
- [Состояние реализации](implementation-state.md) — реализованные возможности,
  совместимость, результаты проверок и оставшиеся задачи.

Инструкции по запуску находятся в [корневом README](../README.md), подробности
backend — в [backend/README.md](../backend/README.md), установка и обновление —
в [deploy/README.md](../deploy/README.md).

Исторические технические задания удалены из рабочего дерева; их исходные
тексты сохранены в истории Git. Актуальные ограничения и незавершённые проверки
перечислены в состоянии реализации. Прежние корневые документы
`PYTHON_PROJECT_ARCHITECTURE.md` и `IMPLEMENTATION_STATE.md` теперь называются
`docs/architecture.md` и `docs/implementation-state.md`.
